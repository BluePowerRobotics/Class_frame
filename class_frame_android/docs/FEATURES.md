## A. 悬浮层内容（来源：class_frame.py）

### A1. 内容形态矩阵

悬浮层由"停靠位置（dock）× 样式（secondStyle）"决定外观，共 5 种内容形态：

| dock | secondStyle | 形态 | 外观 |
| --- | --- | --- | --- |
| left / right | false | `edge_text` | 课表逐项竖排（左右两侧，每项一行） |
| upper | false | `edge_text` | 课表逐项横排，底部一条亮灰细进度条 |
| left / right | true | `edge_bar` | 贴边（flush）的纯进度条，宽度 = 进度条宽度 |
| upper | true | `edge_bar` | 贴顶的纯进度条，高度 = 进度条宽度 |
| center | false | `center_simple` | 顶部进度条 + `HH:MM:SS` 时钟 + 课表一行 |
| center | true | `center_editor` | 日期切换行 + 课表行 + 候选课程网格（拖拽换课） |

- [ ] 五种形态全部实现，切换时窗口尺寸随之变化
- [ ] 窗口背景纯黑，整体不透明度 0.92

### A2. 课表内容

- [ ] 内容 token 序列 = `["周", 星期, "|"] + 当天课表`，共 `n+3` 项
- [ ] `周`、周一至周日、`|` 属于特殊 token，不计入课节序号，也不参与高亮映射
- [ ] 当前课节（`highlight`）显示为黄色，其余白色
- [ ] 字号由 dock 与状态决定：横向基准 `文字大小`、竖向基准 `竖直显示的文字大小`，再乘对应缩放系数
- [ ] 单字字号按 `fpx / len(text)^0.5`（横向）或 `fpx / len(text)^0.7`（竖向）自适应，文本过长自动缩小而不是溢出
- [ ] 竖向模式下 `|` 显示为破折号

### A3. 进度条

- [ ] `edge_bar`：全长白色，`upper` 由中间向两侧收缩，`left/right` 由中间向上下收缩
- [ ] `edge_text`：仅上课中且开启"上课显示倒计条"时显示，厚度为 `0.25 × 字号`，颜色 `#C0C0C0`，位置贴下/贴内侧
- [ ] `center_simple`：顶部白色横条，高度 `fpx/3`
- [ ] 进度比例 `ratio = left_sec / total_sec`，钳制在 0–1

### A4. 上课提示

- [ ] 每节课开始后的前 N 秒（`上课提示时长`，默认 6 秒）显示提示词 + 课名，黄色
- [ ] `upper` 下为上下两行（提示词在上、课名在下）；`left/right` 下为左右并排
- [ ] 提示期间不使用普通课表布局，提示结束回到当前样式
- [ ] 提示词取 `开始提示`，课名为当前课节名；课名为特殊 token 或"无"时不显示提示
- [ ] `center` 布局下不显示上课提示

### A5. 下课倒计时（独立悬浮窗）

- [ ] 课间与放学后显示独立窗口，`upper` 为单行 `mm:ss`，`left/right` 为 `MM` / `SS` 上下两行
- [ ] 未进入倒计时段（刚下课的前 N 秒）显示 `结束提示` 文字
- [ ] 窗口宽度在 `left/right` 下钳制为主课表条宽度
- [ ] `center` 布局与 `edge_bar`（非放学）不显示倒计时
- [ ] 放学后 10 分钟进入 closing 状态，显示总长 600 秒的倒计时

### A6. 交互

- [ ] 点按（位移不超过约 3px）切换 secondStyle
- [ ] 拖动超过阈值后进入移动：以窗口当前 dock 为起点，跨过屏幕 1/4 分界线时切换 dock，并套用该 dock 的"拖动默认样式"
- [ ] 拖动过程中跟手采用非线性阻尼（`fx = 0.1 / (|dx| / screenW + 0.1)`），并保证窗口完整留在屏幕内
- [ ] 松手后弹性归位到该 dock 的基准位置
- [ ] `center_editor` 下由课表两侧空白区域承担拖动，候选项拖到课表格子上替换课程
- [ ] 拖拽替换的命中阈值、选中项高亮、松手落盘与 Python 版一致
- [ ] 修改结果写入 `data.json`（`[日期, tokens]`），并同步当天视图

### A7. center 内置编辑器

- [ ] 进入编辑形态时日期重置为今天，可编辑副本同步当天课表
- [ ] `<` / `>` 切换日期，切换后按星期或 data.json 记录加载对应课表
- [ ] 候选课程按每行 6 个均分格点排布
- [ ] 离开编辑形态时若有未落盘修改，自动写入 data.json

## B. 悬浮层生命周期与调度（Android 新增）

| 能力 | 说明 |
| --- | --- |
| 开机自启 | 受"启用开机自启"开关控制，默认 false；开启后随系统启动拉起前台服务并显示悬浮层 |
| 开机显示 | 服务启动即按当前时间状态渲染悬浮层 |
| 放学隐藏 | 当天最后一节下课 10 分钟后隐藏悬浮层（原 Python 为退出进程，Android 改为隐藏并保留服务/排程） |
| 次日重现 | 次日首节课开始前 1 小时重新显示悬浮层 |
| 时间偏移 | 沿用 `时间偏移（秒）`，所有时间判断基于"系统时间 + 偏移" |
| 时钟变更 | 系统时间/时区变化后重新计算状态并重排下一次唤醒 |

- [ ] 次日重现直接按次日第一节开始时间减 1 小时计算，不特殊处理"全天无课"的日子
- [ ] 设备重启后排程可恢复（BOOT_COMPLETED + 持久化下一次唤醒时间）

## F. 权限与系统集成

- [ ] `RECEIVE_BOOT_COMPLETED`：开机自启
- [ ] `SYSTEM_ALERT_WINDOW`：悬浮在其他应用上方，需跳系统设置授予
- [ ] `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`：电池优化豁免
- [ ] 前台服务：Android 14+ 声明 `foregroundServiceType`，Android 8+ 建立通知渠道，Android 13+ 申请通知权限
- [ ] 精确闹钟：Android 12+ 检查并引导授予"闹钟与提醒"权限
- [ ] 服务看门狗：被系统回收后按需恢复悬浮层与下一次排程

## G. 平台差异与不做项

- [x] "上课置顶/下课置顶"复用为"上课/下课隐藏悬浮层"（见 C4）
- [ ] 窗口类型回退：API 26+ 用 `TYPE_APPLICATION_OVERLAY`，API 24–25 用 `TYPE_PHONE`
