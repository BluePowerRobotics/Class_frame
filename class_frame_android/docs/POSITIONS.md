# 单课默认位置（三层体系）

解决"每一节课用哪种形态"的问题：①全局给一个兜底，②每日可以按"周几 × 第几节"覆盖，
③每课可以精确到每节课覆盖。

## 值域

| 界面 | 内部值 | dock | secondStyle | 悬浮层形态 |
| --- | --- | --- | --- | --- |
| 左表 | `left_table` | left | false | 边缘文字 |
| 左条 | `left_bar` | left | true | 边缘进度条 |
| 上表 | `upper_table` | upper | false | 边缘文字 |
| 上条 | `upper_bar` | upper | true | 边缘进度条 |
| 右表 | `right_table` | right | false | 边缘文字 |
| 右条 | `right_bar` | right | true | 边缘进度条 |
| 时钟 | `time` | center | false | 居中·时钟 |
| 编辑 | `edit` | center | true | 居中·编辑器 |
| 默认 | `default` | — | — | 回退上一级（仅②③） |

①全局 8 项（无"默认"）；②每日、③每课各 9 项。

## 存储

### config.json

```json
"全局日程": { "上课": "upper_bar", "下课": "upper_table" },
"每日日程": { "1": ["upper_table","default", ... ,"time","default"], ... "7": [...] },
"单课日程": { "1": ["default", ...], ... "7": [...] }
```

- 三张表都按"周几 → 每节课的形态"存，行长 = 课节数。
- ②③ 的"未覆盖"写字符串 `"default"`。
- **读取端容错**：`"default"`、`null`、空字符串、缺项、无法识别的值一律当"跟随上级"。
- ①全局与旧键同步：`上课/下课默认位置`、`上课/下课默认使用secondStyle` 在保存①全局时一起更新，
  这样 Python 旧版与旧数据仍能读懂。
- 已废弃并会被删除：`拖动默认样式`、`拖入*时使用secondStyle`。

### data.json

```json
["2026-09-23",
 ["周","三","|","英", ...],
 ["upper_bar","upper_bar","left_table", "", "", ...]]
```

- 第 3 项与课节一一对应，**只写解析后的真实形态**，不写 `"default"`；"没有覆盖"用空字符串。
- 旧记录没有第 3 项时，解析链**不进入③每课**。
- 旧版读新数据安全：两版的校验都只统计 `rec[1]` 的非分隔符数量，多出的第 3 项被忽略。

## 解析链

```
data 第3项  →  ③单课日程[周几][节]  →  ②每日日程[周几][节]  →  ①全局日程[上课/下课]
```

## 记忆路径（拖动 / 点按 / 编辑之后）

1. 结果与操作前的生效值相同 → **什么都不写**（无论当天有没有调课记录）。
2. 确实变了，且这一格的**课节种类与 config 一致**（当天的调课记录没有替换它）→ 写 **③单课日程**。
3. 当天有调课记录且该格被替换过 → **不写 config**，把真实形态写进 **data.json 第 3 项**。
4. 悬浮层里用居中编辑器换课时，位置写进 **data.json 那条覆盖记录**（真实形态），
   覆盖记录承载"这一天这节课长什么样"，位置是它的一部分；不写 config 的②每日。

判定实现：`data_overrides_lesson()` 比较"该日记录里的这节课"与"config 模板里同一节"。

## 对调

对调时交换两天的 tokens **与位置数组**，写入的是解析后的真实值（不写 `"default"`）。
单节对调时，位置跟着课走。

## 界面

| 位置 | 形式 |
| --- | --- |
| edit → 参数 → ①全局 | 上课、下课两个 8 选下拉 |
| edit → 课表 → 周日右侧 | ②每日：列首 `每日` / `× 周X` 开合，行内 9 选 |
| edit → 参数 → 按钮 | ③每课：文本框整表编辑（每行一天，逗号分隔内部值） |
| setclass 导入 | 班级模板自带三张表，导入时整体覆盖 |

Python 与 Android 功能对齐，同样不做③每课的图形编辑。
